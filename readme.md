Ελεάνα έκανα την αρχή.

1. έφτιαξα ένα index.html το οποίο είναι η ιστοσελίδα. προς το παρόν δεν κάνει τίποτα :-)
2. έφτιαξα την main.go η οποία καλεί την net/http η οποία έχει τις εντολές για τον server 

Για να το τρέξεις να το δεις:

1. τρέχεις go run main.go και σου εμφανίζει το μύνημα: Server starting at http://localhost:8080
2. ανοίγεις έναν web browser και γράφεις στην διεύθυνση: http://localhost:8080

Δες το, δες τα σχόλια για να καταλάβεις τι κάνει η κάθε γραμμή του κώδικα, τρέξτο και συνέχισε το.
